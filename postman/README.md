# Postman Collection

> The Postman collection for CampusFind AI will be added here once the API endpoints are implemented.

## What to expect

The collection will cover:

- **Health checks** – Verify both the Node.js backend and Python ML service are running.
- **Admin endpoints** – User management and administrative operations.
- **Claim endpoints** – Lost/found item claim workflows.
- **Notification endpoints** – In-app notification management.
- **Image upload** – Multer-based file uploads for items.
- **Image similarity** – ML-powered image matching via the FastAPI service.

## How to import

1. Open **Postman**.
2. Click **Import** → select the JSON collection file from this folder.
3. Set up an environment with variables like `base_url`, `token`, etc.
